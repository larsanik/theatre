Создайте API для внешнего агрегатора билетов
Условия: агрегатор билетов показывает все мероприятия театра и дает возможность забронировать на них билеты.
Выполните следующие шаги, чтобы создать API для внешнего агрегатора билетов:

   1. Создайте приложение API и подключите его к проекту.
   2. Создайте тестовый эндпоинт, который передает список всех актеров театра.
   3. Создайте эндпоинт для агрегатора, чтобы передавать ему полную информацию о мероприятиях.
   4. Настройте функцию смены пользователя.
   5. Создайте эндпоинт, который выводит список бронирований. Убедитесь, что пользователь может смотреть только свои бронирования.
   6. Настройте для пользователей возможность создавать новые бронирования.
   7. Настройте для пользователей возможность удалять и редактировать свои бронирования.
   8. Добавьте пагинацию.
